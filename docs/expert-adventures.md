# Magic Kingdom and Moon Mission

Both released worlds can be explored immediately. Level 7 is Advanced; Level 8 is Expert. Existing worlds and Signal Lost retain their resolution rules.

## Shared interactive contract

Each of the five stages contains six owned controls, distributed by control index modulo the connected mission roster (2–6 seats). Every seat has at least one interactive responsibility and a distinct subset of six private clues. The public snapshot contains observable mechanism state, control ownership and readiness, never another seat's clues or validation targets.

`mechanism` commands include adventure, run, round, attempt and current mechanism version. The server checks ownership and valid options. A real edit advances the version and clears everyone's consent. Adjustments do not spend attempts. Only the Captain's final launch, after every connected explorer is Ready, freezes the shared settings for normal server resolution. Stale commands and edits after launch are rejected. Existing timeout, two-attempt retry, Team Assist and badge behavior apply.

The refined illustrated maps are static WebP backgrounds. HTML markers, character/vehicle movement and synchronized SVG mechanisms remain independent. Travel is 3.5 seconds including celebration, immediately skippable, and never gates the server. Reconnect and reduced motion render the authoritative current location.

Successful stages commit their chosen plan; Team Assist commits a coherent recovery, marks assistance and gives no badge. Replay starts a fresh board while retaining session results. No supported equipment choice forces Team Assist: all four kits, both relay modes and five-badge completion are tested. This is room/session state, not an account profile or database record.
